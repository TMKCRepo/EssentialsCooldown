EssentialsCooldown is a plugin I made for my own server. I decided to make it public just for the heck of it. I have not seen any similar plugins so I thought maybe it'd be useful for someone else.

EssentialsCooldown requires EssentialsX to function

What it does is enables Cooldowns for the most commonly Player commands in EssentialsX with configurable cooldowns per command and per rank.

Lets say you want to have two ranks
- Player
- Hyper
You can then edit the config of EssentialsCooldown to set cooldowns for the ranks so that the rank Player has a 24h cooldown of /heal while the Hyper rank has a cooldown of 1 hour (this is an example).  Most of the standard player-ran commands are in there and configurable.

If you want to add in your own commands, you can copy a command section and rename it to the relevant EssentialsX command.
The plugin ONLY supports EssentialsX commands.

Supported Server JARs
- Bukkit (and forks)
- Spigot (and forks)
- PaperMC (and forks)
- Folia
- ShreddedPaper
- MultiPaper


Permissions
- essentialscooldown.<rank> | give this to the rank you want cooldowns for
- essentialscooldown.bypass | bypasses cooldowns
- essentialscooldown.reload | reloads the config
